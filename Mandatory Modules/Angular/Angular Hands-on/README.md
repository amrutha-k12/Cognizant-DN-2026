# 🎓 Student Course Portal


# 📖 Project Description

The **Student Course Portal** is designed as a learning application that demonstrates how Angular applications evolve from a basic project structure into a complete enterprise-ready web application.

Instead of creating separate projects for every exercise, each hands-on builds upon the previous implementation. By the end of the exercises, the application includes routing, reusable components, form validation, API integration, state management, and testing capabilities, closely resembling a production Angular application. :contentReference[oaicite:1]{index=1}

# ⚙️ Installation

Clone the repository.

```bash
git clone https://github.com/your-username/student-course-portal.git
```

Navigate to the project directory.

```bash
cd student-course-portal
```

Install all dependencies.

```bash
npm install
```

Run the Angular application.

```bash
ng serve
```

Open the application.

```
http://localhost:4200
```

Run JSON Server.

```bash
json-server --watch db.json --port 3000
```

Run unit tests.

```bash
ng test
```

Generate production build.

```bash
ng build
```
