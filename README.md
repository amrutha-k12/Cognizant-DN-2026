# Cognizant Digital Nurture Program (DN 5.0) – Java FSE

## Overview

This repository contains my learning journey, hands-on exercises, assignments, and implementations completed as part of the **Cognizant Digital Nurture Program (DN 5.0) – Java Full Stack Engineer Track**.

The program focuses on developing practical skills in software development, backend engineering, frontend technologies, database management, testing frameworks, microservices, and modern development practices.

All **mandatory hands-on modules** have been completed and are organized week-wise below, in the actual order they were done.

---

## 7-Week Mandatory Modules Plan

| Week | Focus Area | Modules Covered | Exercises |
|------|------------|------------------|-----------|
| **Week 1** | Frontend – React | React | 10 |
| **Week 2** | Foundations | Design Principles & Patterns | 2 |
| **Week 3** | Database | PL/SQL Programming | 2 |
| **Week 4** | Data Structures | Data Structures & Algorithms, TDD using JUnit 5 & Mockito, SLF4J Logging | 8 |
| **Week 5** | Spring Core | Spring Core and Maven | 3 |
| **Week 6** | Spring Boot & Microservices | Spring Data JPA with Spring Boot & Hibernate, Spring REST using Spring Boot 3, Microservices with Spring Boot 3 and Spring Cloud | 9 |
| **Week 7** | Version Control & Frontend | GIT, Angular | 6 |

---

### Week 1 – Frontend: React
- **React**
  - 10 hands-on exercises covering components, state, props, hooks, and application structure

### Week 2 – Foundations
- **Design Principles & Patterns**
  - Implementing the Singleton Pattern
  - Implementing the Factory Method Pattern

### Week 3 – Database: PL/SQL
- **PL/SQL Programming**
  - Control Structures
  - Stored Procedures

### Week 4 – Core Java & Testing
- **Data Structures & Algorithms**
  - E-commerce Platform Search Function
  - Financial Forecasting
- **TDD using JUnit 5 & Mockito**
  - Setting Up JUnit
  - Assertions in JUnit
  - Arrange-Act-Assert (AAA) Pattern, Test Fixtures, Setup and Teardown Methods
  - Mocking and Stubbing
  - Verifying Interactions
- **SLF4J Logging Framework**
  - Logging Error Messages and Warning Levels

### Week 5 – Spring Core
- **Spring Core & Maven**
  - Configuring a Basic Spring Application
  - Implementing Dependency Injection
  - Creating and Configuring a Maven Project

### Week 6 – Spring Boot & Microservices
- **Spring Data JPA with Spring Boot, Hibernate**
  - Spring Data JPA – Quick Example
  - Difference between JPA, Hibernate and Spring Data JPA
  - Implement services for managing Country
  - Find a country based on country code
  - Add a new country
  - Demonstrate Query Methods, O/R Mapping, and HQL/Native Query
- **Spring REST using Spring Boot 3**
  - Create a Spring Web Project using Maven
  - Spring Core – Load Country from Spring Configuration XML
  - Hello World RESTful Web Service
  - REST – Country Web Service
  - REST – Get country based on country code
  - Create authentication service that returns JWT
- **Microservices with Spring Boot 3 and Spring Cloud**
  - Creating Microservices for account and loan
  - Create Eureka Discovery Server and register microservices

### Week 7 – Version Control & Frontend
- **GIT**
  - 5 hands-on exercises covering branching, merging, and collaboration workflows
- **Angular**
  - Angular fundamentals hands-on
